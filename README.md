# Healthcare Risk Prediction App

This project predicts diabetes risk using machine learning based on patient health data.

## 🚀 Live App
https://healthcare-risk-app-aw3vhr8sba9nzcz3g6rhgm.streamlit.app

## 📊 Project Overview
This application allows users to input health parameters and get real-time predictions of diabetes risk using a trained machine learning model.

## 🧠 Dataset Information

This project uses the **Pima Indians Diabetes Dataset**, a widely used healthcare dataset for machine learning.

### Source
https://raw.githubusercontent.com/plotly/datasets/master/diabetes.csv

### Features
- Pregnancies: Number of times pregnant  
- Glucose: Plasma glucose concentration  
- Blood Pressure: Diastolic blood pressure  
- Skin Thickness: Triceps skin fold thickness  
- Insulin: 2-Hour serum insulin  
- BMI: Body mass index  
- Diabetes Pedigree Function: Diabetes probability function  
- Age: Age of patient  

### Target Variable
- Outcome  
  - 0 → No diabetes  
  - 1 → Diabetes  

## ⚙️ Tech Stack
- Python  
- Scikit-learn  
- Pandas  
- Streamlit  

## 🔍 Model Details
- Algorithm: Random Forest Classifier  
- Type: Classification Model  
- Use Case: Healthcare Risk Prediction
